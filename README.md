# Affirmation Avatar App 

A friendly interactive web app featuring a virtual avatar that greets 
users with time-aware messages and delivers randomized affirmations at 
the click of a button.

---

## What it does

- Greets the user based on the time of day (morning, afternoon, evening)
- Displays a random affirmation each time the button is clicked
- Avatar animates with a bounce effect on interaction
- Affirmation text fades in and out smoothly between messages
- Fully responsive — works on desktop and mobile

---

## Built with

- HTML
- CSS (Flexbox, animations, transitions)
- JavaScript (DOM manipulation, event listeners)
